The Side Door — SSRF to stolen credentials

Briefing

CorpTech's internal reporting tool lets staff preview data from any URL — a convenience feature nobody thought to restrict. The server it runs on has its own cloud credentials. See if the preview feature can be convinced to fetch something it shouldn't.

Hint: cloud instances fetch their own credentials from an internal-only metadata address.

Vulnerable app: launch to get the URL

Once you've found the SSRF parameter, try pointing it at:
http://hard-metadata:9000/latest/meta-data/iam/security-credentials/

That returns a role name. Append it to the same path to get real credentials.
