The Spare Key — a privilege escalation chain

Briefing

An ops engineer at CorpTech left some notes sitting in a storage bucket — including a set of temporary credentials and a role ARN they probably shouldn't have mentioned together. Find the leak, use what's in it, and see how far those credentials actually reach.

Hint: bucket names tend to follow the pattern corptech-ops-notes-*

Target endpoint: http://localhost:4566

Find the note: aws s3 cp s3://<bucket-name>/ops-notes.txt - --endpoint-url http://localhost:4566 --no-sign-request

Assume the role it mentions: aws sts assume-role --role-arn <role-arn> --role-session-name pwn --endpoint-url http://localhost:4566
